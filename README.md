
# 🎓 Student Performance Prediction

## 📌 Project Description

**Student Performance Prediction** is a Machine Learning-based web application designed to predict a student's academic performance based on various factors such as study hours, attendance, sleep hours, internet usage, assignments completed, and previous scores.

The system uses a trained **Machine Learning model** to analyze the student's academic information and predict their expected exam score/performance. The project provides a simple and user-friendly web interface where users can enter student details and get prediction results.

## 🚀 Features

* Student registration system
* Student performance prediction using Machine Learning
* Prediction based on academic and personal factors
* User-friendly web interface
* MySQL database integration
* Stores student information and prediction results
* Displays predicted score and performance category
* Flask-based backend
* Machine Learning model using Python
